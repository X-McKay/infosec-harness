# Agent quality qualification attempts (2026-09-29 to 2026-09-30)

The [plan](AGENT_QUALITY_PLAN.md), [review](AGENT_QUALITY_REVIEW.md),
[gate fixes](AGENT_QUALITY_GATE_FIXES.md) and the `agent-quality/` summaries record the live
qualification sweeps of all eleven agents against one self-hosted model, the intake contract
trials (v9 to v17) and the [canonical qualification checkpoint](agent-quality/canonical-qualification-20260930.md).
They include the owner's decision to set the task-success floor to 0.75. They prove that
qualification was attempted and **failed or stopped incomplete** on the named commits, and why;
held-out cases were never admitted. They do not qualify any agent, they describe evaluator
versions and retained intake generations that no longer exist, and some referenced paths (for
example the token-ceiling overlay, now under `evals/experiments/calibration/`) have moved.
Endpoint names and workstation paths were redacted on 2026-10-04.
